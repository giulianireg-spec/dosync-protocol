# Design principles

**This document moved to [`../DESIGN-PRINCIPLES.md`](../DESIGN-PRINCIPLES.md).**

There were two of these for three months — this one and the copy in the
repository root — and they drifted 265 lines apart while both were being
edited. Neither was a stale duplicate of the other: this file held the rules on
adapters, optional dependencies and how to write a test; the root held the
founding principle and the most recent safety decisions. Anyone reading one of
them had a partial view of the rules this project runs by, and the code
referenced this one while the newest decision lived in the other.

They are merged in the root file now. This pointer stays because published
articles and external links reference this path, and breaking them to tidy a
directory would be a poor trade.
