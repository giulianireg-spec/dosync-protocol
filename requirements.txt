# ─────────────────────────────────────────────────────────────────────────────
# DoSync Protocol — dependencies
#
# DoSync is an open protocol. The hub core depends ONLY on a web framework and a
# schema validator. Every device adapter brings its OWN library, and each is
# OPTIONAL: the adapter imports its library lazily and degrades to simulated mode
# (or disables itself) when the library is absent. Installing DoSync does NOT
# force you to install libraries for hardware you don't use.
#
# Install only what your deployment needs:
#   pip install -r requirements.txt          # core + schema validation
#   pip install pywizlight                    # only if you use Philips WiZ
#   pip install twilio                        # only if you use SMS notifications
#   pip install paho-mqtt                     # only if you use MQTT devices
#   pip install aiohttp                        # only if you use the Home Assistant bridge
#   pip install bleak                          # only if you enable the BLE adapter
#   pip install pymavlink                      # only if you control a MAVLink vehicle (drone)
# ─────────────────────────────────────────────────────────────────────────────

# ── Core — required for the hub to run ───────────────────────────────────────
#
# These ranges are VERIFIED, not aspirational (corrected 2026-07-14). The previous
# floors (fastapi>=0.100.0 with pydantic>=2.0.0) were not merely untested — that
# combination is UNINSTALLABLE: pip reports ResolutionImpossible, because those two
# versions have conflicting requirements. The file declared a compatibility contract
# that could not exist. The floors below are the lowest combination that actually
# resolves AND passes the full suite, checked together rather than one at a time.
#
# Upper bounds are not distrust of upstream: they mean "nobody has run the suite
# against that major version yet". Raise them by testing, not by hoping.
#
# NOTE they do not bound TRANSITIVE deps: starlette 1.3.1 arrived through fastapi
# despite a fastapi ceiling and moved its TestClient to httpx2 — which is why test
# dependencies are declared explicitly in requirements-dev.txt.
#
# Verified 2026-07-14 — floor (fastapi 0.115.0 / uvicorn 0.23.0 / pydantic 2.7.0 /
# jsonschema 4.18) and current (fastapi 0.139.0 / pydantic 2.13.4 / starlette 1.3.1)
# each pass 548/548. CI checks both legs on every push.
fastapi>=0.115.0,<1.0
uvicorn>=0.23.0,<1.0
pydantic>=2.7.0,<3.0

# ── Schema validation — params_schema is JSON Schema draft 2020-12 (protocol 0.3)
# Strongly recommended: without it, schema validation degrades gracefully
# (skipped with a warning). The certification suite requires it.
jsonschema>=4.18,<5.0

# ── Optional — device adapters ───────────────────────────────────────────────
# Each line is needed ONLY if you use that adapter. The hub runs without them;
# the corresponding adapter falls back to simulated mode or disables itself.
#
# pywizlight>=0.5.0     # Philips WiZ bulbs (UDP local)
# twilio>=8.0.0         # SMS notifications
# paho-mqtt>=2.0.0      # MQTT devices
# aiohttp>=3.8.0        # Home Assistant bridge
# bleak>=0.21           # universal BLE adapter (DOSYNC_BLE_ENABLED=true)
bleak>=0.21
pyyaml>=6.0
aiohttp>=3.8.0
paho-mqtt>=2.0.0
