# Tutorial

**This moved to [`docs/DEVICE-INTEGRATION.md`](docs/DEVICE-INTEGRATION.md), and
was renamed for what it does.**

It is not the shortest path into DoSync — it builds a device that speaks the
protocol, and it needs Docker, a broker and Python before its first step. Its
name said otherwise while it sat in the repository root, which is where someone
looks first.

**To install a hub and see your devices**, the [README](README.md) takes about
five minutes and needs none of that: discovery and adoption happen in the
dashboard, without a terminal.
