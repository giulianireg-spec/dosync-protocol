# DoSync Protocol — Node.js Implementation

**This implementation has moved to its own repository.**

## ➜ [giulianireg-spec/dosync-node](https://github.com/giulianireg-spec/dosync-node)

The Node.js implementation of the DoSync Protocol is now maintained as a standalone project
to better demonstrate that the protocol spec is clear enough for independent third-party implementations.

**Certification:** Standard 32/32 ✅

```bash
git clone https://github.com/giulianireg-spec/dosync-node
cd dosync-node
npm install
DOSYNC_TOKEN=<token> node src/server.js
```

See [CONFORMANCE.md](CONFORMANCE.md) for the full certification report.
